Overlays para OBS

Esta pagina solo explica como usarlos. Cada overlay tiene fondo transparente y se actualiza solo, sin recargar, leyendo data/donors.json.

Como agregarlos en OBS

Fuentes > + > Navegador (Browser Source). Pega la URL, pon el ancho y alto de la tabla y listo. No pegues CSS ni marques "Apagar la fuente cuando no esta visible" si no quieres que se pare.

La recomendada: todo en una sola pagina

Fuente de navegador de 1920 x 1080 en X 0, Y 0, encima de tus cajas. Trae solo texto (sin cajas ni fondo) en su lugar: lista de donadores a la izquierda, Next streams a la derecha y el monto del prize pool. Si la agregas dos veces, recorta cada copia con Alt + arrastrar. Se puede ocultar una parte con ?donors=0, ?streams=0 o ?prize=0.

Next streams: el texto sale del archivo data/next-streams.json. Para cambiarlo, edita ese archivo en GitHub (lapiz de editar) y guarda; el overlay se actualiza solo en ~1 minuto. Cada elemento tiene when (dia y hora, en dorado) y title (nombre, en blanco); se muestran hasta 5.

Opciones en la URL (todas opcionales)

?refresh=30Cada cuantos segundos se actualiza (minimo 10, por defecto 60)
?count=3Cuantos donadores muestra el Top (1 a 10, por defecto 5)
?edition=2026Otra edicion (2027 por defecto). all suma todas
?lines=1Dibuja lineas separadoras entre filas (en endingstream y en la lista de donadores)
?bg=ffffffFondo de prueba para ver el overlay en un navegador normal (en OBS no hace falta)
?panel=noneSin fondo azul (completamente transparente). solid = fondo solido

Se pueden combinar: top-donors.html?count=3&refresh=30

Cuando cambian los datos

Los datos de Matcherino se actualizan en GitHub cada ~10 minutos y la pagina los lee sola. Si haces un cambio en el codigo y no lo ves en OBS, clic derecho sobre la fuente > Actualizar cache de la pagina actual.
